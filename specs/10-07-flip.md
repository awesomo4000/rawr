# Spec 10-07: `Roaring64Bitmap` flip

First Phase-2 parity chunk of [64-bit Roaring](10-roaring64.md), and the
substantial one. Toggle membership of every value in a range: present → absent,
absent → present.

## Features

| rawr 64-bit (new) | CRoaring | Semantics |
|---|---|---|
| `flip(allocator, lo, hi) !Self` | `roaring64_bitmap_flip_closed` | new bitmap, `[lo, hi]` **inclusive** toggled |
| `flipInPlace(lo, hi) !void` | `roaring64_bitmap_flip_closed_inplace` | mutate self, inclusive |

**House style: inclusive `[lo, hi]`** (matches rawr's `addRange`/`removeRange`).
CRoaring exposes *both* a half-open `flip`/`flip_inplace` (`[min, max)`) and an
inclusive `flip_closed`/`flip_closed_inplace` — **oracle the inclusive rawr op
against `flip_closed`.** Never mix the half-open variant into the inclusive
comparison.

## Implementation

Flip = XOR with the full range, exactly as the 32-bit `flip` uses the
XOR-with-range identity. Same key-span decomposition as `addRange` (10-03):

- `lo_key == hi_key`: `findOrCreateBucket(key)`, delegate `bm.flip(low32(lo),
  low32(hi))` (32-bit inclusive flip); prune if the sub-bitmap ends empty.
- spanning keys `lo_key … hi_key`: first key flips `[low32(lo), 0xFFFFFFFF]`,
  interior keys flip the **entire** `[0, 0xFFFFFFFF]` (find-or-create each), last
  key flips `[0, low32(hi)]`.

**Prune + create discipline:** flipping can *empty* a bucket (all bits toggled
off) → `dropBucket`; and it can *require* a new bucket for a key that had none
(all-absent → all-present). Reuse the 10-01 OOM-rollback + 10-03 widened-cursor
(`u64` key loop, `if (key == end_hi) break`) machinery. Invalidate the cardinality
cache.

## Wrapper decls

```c
roaring64_bitmap_t *roaring64_bitmap_flip_closed(const roaring64_bitmap_t *r, uint64_t min, uint64_t max);
void roaring64_bitmap_flip_closed_inplace(roaring64_bitmap_t *r, uint64_t min, uint64_t max);
```

## Tests / oracle

- Inline: flip within a single key; flip spanning ≥3 keys (interior fully
  toggled); flip that empties a bucket (assert prune / `expectNoEmptyBuckets`);
  flip that creates buckets from all-absent; double-flip identity
  (`flip(flip(x)) == x`); flip at `maxInt(u64)` boundary (widened cursor).
- `difftest64` + `validate64`: extend the range-mutation path — apply
  `flip`/`flipInPlace` and assert agreement against `roaring64_bitmap_flip_closed`
  / `_inplace` over the generated corpus, across key boundaries and the `u64`
  top edge.

## Acceptance

- `flip`/`flipInPlace` implemented via XOR-with-range delegation, inclusive
  semantics, empty-bucket prune + bucket-create rollback honored.
- Oracled against `flip_closed`/`flip_closed_inplace` (not the half-open variant).
- `zig build test test64 validate64 difftest64` green; no 32-bit regression.
