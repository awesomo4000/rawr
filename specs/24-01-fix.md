# Spec 24-01: Correct the select row + conditional fix

Second chunk of [select parity](24-select-parity.md). One **unconditional** deliverable (correct
the benchmark comparison) and one **conditional** deliverable (a select optimization, gated on
`24-00`).

## Gate

- `24-00` complete: the matrix-selected public-API select ratio (per host) and rawr's dominant
  select cost known, sanity checks passing.

## Unconditional — correct the canonical `select` row

Move the `select` row to the **matrix-selected public-API comparison** (likely rawr-noinline vs
CRoaring-in-C), so the canonical number reflects a fair public select call — not the Zig→C FFI or
an inline-vs-noinline mismatch. Re-run, update `docs/parity-measurement.md`. Still one `select`
row (no manifest count change). Done regardless of the perf outcome.

## Conditional — perf fix (threshold-gated)

Threshold (matrix-selected public-API rawr vs CRoaring, per host):
- **≤ 1.10x on both hosts** → parity; no kernel change (row correction only).
- **> 1.10x on either host** → optimize rawr's select, lever following `24-00`:
  - **container-skip dominates:** a cheaper cumulative-cardinality traversal / skip, or a cached
    prefix structure — any cached index must stay correct across mutation;
  - **intra-container select dominates:** tighten that path per container type.
- **Rerun** when a host's ranges straddle 1.10x before deciding.

## Constraints / acceptance

- **Correctness:** `select` returns the same value for every rank — differential green, incl.
  array/bitset/run and empty/boundary ranks. Existing `select` semantics unchanged.
- Measured on the canonical harness, single rawr non-allocating tuple vs CRoaring, five fresh
  processes, median + range, both hosts.
- **Phase-2 GO (if a fix is made):** matrix-selected public-API select **≤ 1.10x on both M4 and
  Zen 4**, no canonical row regressing >5% vs the latest committed corrected baseline (rerun on
  overlap), differential green.
- A documented "already ≤ 1.10x, row corrected, no fix" is an acceptable terminal outcome.
- Validation: `zig build test`; `zig build difftest`; `run-compare-bench.sh` on both hosts;
  `ReleaseSafe` / `ReleaseFast` green.
