## Constraints fixed now (any candidate inherits these)

- **Allocator-genericity preserved.** `std.mem.Allocator.alloc` returns **undefined**
  contents by contract — including `page_allocator`. A "skip zeroing" experiment may not
  assume any `std.mem.Allocator`-provided memory is zero; it must use an explicitly
  known-zero benchmark allocator or a direct OS mapping, and any production form must not
  break the arbitrary-allocator / arena / `Owned` contract.
- **Lifecycle-honest timing.** Report **both** construction-only timing (parity with the
  2.19x figure) **and** full construct + repair + destroy lifecycle timing — a zero-on-free
  pool that merely moves the memset to teardown must not be able to look like a win.
- **No correctness change**; differential tests green; leak-safe.

## Acceptance (numeric gates set against the `20-00` baseline)

- Closes **≥ [threshold, set from `20-00`]%** of the attributed dominant term, **without**
  lifecycle regression and **without** breaking allocator-genericity or correctness, beyond
  noise on the spec-16 M4 environment (five process runs, median + range).
- Existing lazy OR / repair semantics and numbers unchanged elsewhere.
