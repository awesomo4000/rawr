# Spec 11-05: SIMD `vector16` array kernels (x86)

Chunk of [array-kernel performance](11-array-kernel-perf.md). The SIMD tier, and a
different risk class from the portable chunks: hand-written 128-bit kernels with
inline asm and headroom/trampling footguns. Land it as a deliberate,
heavily-fuzzed opt-in, **intersect first**. Behavior-preserving (bit-identical
results; the reference bench cross-verifies).

**Scope: the write and cardinality intersect kernels only.** CRoaring does not
vectorize the boolean nonempty path, and gallop/merge already early-exit it cheaply
— leave the **boolean** intersect on the 11-01 gallop/merge dispatch. So the SIMD
dispatch arm is added for `intersectWrite*` and `intersectCard*` only.

**Dependency order:** after [11-01](11-01-ratio-dispatch.md) (wires into its
balanced dispatch arm) and [11-00](11-00-kernel-extraction-bench.md) (module +
bench). Shares the shuffle table + skeleton with
[11-06](11-06-neon-simd.md) — structure the code so 11-06 reuses it.

## Module + allowlist

**New file `src/array_simd.zig`** — arch-specific kernels, imported **privately by
`array_kernels.zig`** (the balanced dispatch arm calls it); nothing else imports it.
**Add `src/array_simd.zig` to `build.zig.zon` `.paths`** (production module) and run
the downstream-package build check. **Register the SIMD write + cardinality kernels
in `array_kernels.zig`'s `bench_kernels` descriptor list** (from 11-00) so `bench_aa`
times and cross-checks them separately from merge without importing `array_simd.zig`. Reference: CRoaring `array_util.c`
(`intersect_vector16`, `union_vector16`, `xor_vector16`), vendored in
`vendor/roaring.c`.

## The equal-any primitive — decision (measurement-gated)

CRoaring's kernel is **128-bit SSE**: it uses the **SSE4.2 `_mm_cmpestrm` equal-any**
to test "does each lane of A appear anywhere in B" in one instruction, then
`pshufb`-compacts. The sketch below instead uses **8 broadcast compares + ORs**.

- **Primary: generic 8-broadcast compare-any** (below) — simpler, fewer asm seams.
  Measure against the 4× target.
- **Escalation (only if it misses 4×): CRoaring's `_mm_cmpestrm` equal-any** via
  inline asm, behind an `inline fn compareAny` seam so it swaps without touching the
  kernel body.

## Gating — name every feature the body uses

The kernel is 128-bit (8×u16) — **do not gate on AVX2.** `vpshufb` is the **VEX**
(3-operand) *encoding* of the **SSSE3** `pshufb` *operation*, so it needs **both**
`.avx` and `.ssse3`:

```zig
const HAS_SIMD = builtin.cpu.arch == .x86_64 and
    std.Target.x86.featureSetHas(builtin.cpu.features, .avx) and
    std.Target.x86.featureSetHas(builtin.cpu.features, .ssse3);
    // + `and … .sse4_2` when the cmpestrm equal-any path is compiled in
```

- Default: `.avx and .ssse3` + `vpshufb`.
- `cmpestrm` escalation additionally requires `.sse4_2`.
- SSSE3-without-AVX coverage (if ever wanted): legacy two-operand `pshufb %xmm2,
  %xmm1` (destructive) behind the same seam, gated on `.ssse3` alone.

An SSSE3-only gate with a `vpshufb` body is invalid — gate and asm must agree.
Comptime gating is correct for rawr (per-target builds; runtime dispatch out of
scope). Baseline builds without the feature keep the merge path.

## Shuffle table (shared with 11-06)

256 entries × 16 bytes = 4 KB, comptime-generated:

```zig
fn genEntry(comptime mask: u8) [16]u8 {
    var e: [16]u8 = @splat(0xFF);
    var out: usize = 0;
    inline for (0..8) |i| {
        if (mask & (1 << i) != 0) { e[out*2] = @intCast(i*2); e[out*2+1] = @intCast(i*2+1); out += 1; }
    }
    return e;
}
pub const shuffle_mask16: [256][16]u8 = blk: {
    var t: [256][16]u8 = undefined;
    for (&t, 0..) |*e, i| e.* = genEntry(@intCast(i));
    break :blk t;
};
```

## Intersect kernel shape (generic compare-any path)

**Rounded block ends — required.** Compute the block boundaries once and test them
before every 8-lane load, so the vector loop never reads past the arrays:

```zig
const block_end_a = A.len & ~@as(usize, 7);   // largest multiple of 8 ≤ A.len
const block_end_b = B.len & ~@as(usize, 7);

while (ia < block_end_a and ib < block_end_b) {
    const va: @Vector(8, u16) = A[ia..][0..8].*;
    const vb: @Vector(8, u16) = B[ib..][0..8].*;
    var matches: @Vector(8, bool) = @splat(false);
    inline for (0..8) |i| { matches = matches | (va == @as(@Vector(8, u16), @splat(vb[i]))); }
    const mask: u8 = @bitCast(matches);
    if (mask != 0) {
        const packed_: @Vector(8, u16) = @bitCast(pshufb(@as(@Vector(16, u8), @bitCast(va)), shuffle_mask16[mask]));
        const scratch: [8]u16 = @bitCast(packed_);   // value @bitCast — no under-aligned *@Vector pointer cast
        @memcpy(out[k..][0..@popCount(mask)], scratch[0..@popCount(mask)]);
        k += @popCount(mask);
    }
    const amax = A[ia + 7]; const bmax = B[ib + 7];
    if (amax <= bmax) ia += 8;
    if (bmax <= amax) ib += 8;
}
// scalar merge for the sub-8 tails (ia..A.len, ib..B.len)
```

`pshufb` via inline asm (LLVM's generic lowering is backend-sensitive):

```zig
inline fn pshufb(v: @Vector(16, u8), m: [16]u8) @Vector(16, u8) {
    const mv: @Vector(16, u8) = m;
    return asm ("vpshufb %[m], %[v], %[out]"
        : [out] "=x" (-> @Vector(16, u8)), : [v] "x" (v), [m] "x" (mv));
}
```

## Output headroom — via local scratch, not container over-allocation

The kernel produces up to 8 lanes per matching block but only `popCount(mask)` are
valid. **Do not over-allocate the result container** (requesting `min_card + 8` when
`min_card == 4096` rounds `ArrayContainer.init` up to 8192 — doubling the max array
allocation for 16 bytes of slack). Instead compact into a local 8-lane stack scratch
and copy only the valid lanes (as in the sketch: `scratch: [8]u16 = @bitCast(...)`,
`@memcpy(out[k..][0..popCount], scratch[0..popCount])`). The result container is
allocated at its true `min(cardA, cardB)` size. The same scratch makes in-place
variants safe (the 8-wide store lands in scratch, never the input). Debug assert
`k + @popCount(mask) <= out.len`.

## XOR / union kernels — future scope (NOT this chunk)

**Out of scope for 11-05.** SIMD xor/union (sorted-merge network + keep-mask
compaction, ported from CRoaring `union_vector16` / `xor_vector16`) are a **later
follow-up behind the same dispatch** — this chunk's acceptance covers **intersection
only** (write + cardinality). Recorded here so the shape is known; not implemented or
measured in this chunk.
